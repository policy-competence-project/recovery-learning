From-start execution

RoboDojo and real-world tasks

R1: Base failures
R2–R3: preceding-student failures

RoboDojo 10 tasks

50 from-start trials per task and method. Seed-0 configuration. The agent supplies training corrections, not online decisions.

Real world 3 tasks

40 from-start reset trials per task and method. Values report policy-only task success after adaptation using corrections collected on the robot.

One task-round: a collection budget of 30 new independent failure sources, with three corrections per source. Cumulative source budgets are 30 / 60 / 90; corrections from one source are not independent sources.
